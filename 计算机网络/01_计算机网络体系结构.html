01 计算机网络体系结构 ​

本章是计算机网络的入门章节，主要考查网络基本概念、体系结构与性能指标。以选择题为主，时延计算偶尔出现在大题中。

一、计算机网络概述 ​

1.1 计算机网络的定义 ​

计算机网络是一个将分散的、具有独立功能的计算机系统，通过通信设备与线路连接起来，由功能完善的软件实现资源共享和信息传递的系统。

1.2 计算机网络的组成 ​

从组成部分看：硬件（主机/通信链路/交换设备/通信处理机）+ 软件（协议/应用）+ 协议

从工作方式看：

  • 边缘部分：用户直接使用的主机系统（C/S 模式、P2P 模式）
  • 核心部分：路由器、交换机等网络设备，为边缘部分提供连通性和交换服务

从功能组成看：

  • 通信子网：传输介质、通信设备、网络协议（实现数据通信）
  • 资源子网：主机、终端、软件资源（实现资源共享/数据处理）

1.3 计算机网络的功能 ​

  1. 数据通信（最基本的功能）
  2. 资源共享（硬件/软件/数据）
  3. 分布式处理
  4. 提高可靠性
  5. 负载均衡

1.4 计算机网络的分类 ​

分类标准类型
分布范围广域网 WAN / 城域网 MAN / 局域网 LAN / 个人区域网 PAN
传输技术广播式网络 / 点对点网络
拓扑结构总线型 / 星型 / 环型 / 网状型
使用者公用网 / 专用网
交换技术电路交换 / 报文交换 / 分组交换
传输介质有线 / 无线

二、计算机网络体系结构 ​

2.1 分层思想 ​

分层的好处：各层独立、接口灵活、易于实现和维护、促进标准化。

2.2 协议的三要素 ​

要素含义
语法数据与控制信息的格式
语义需要发出何种控制信息，完成何种动作以及做出何种响应
同步（时序）事件实现顺序的详细说明

2.3 三种体系结构 ​

OSI 参考模型（7 层） ​

应用层 → 表示层 → 会话层 → 传输层 → 网络层 → 数据链路层 → 物理层
1
  • 应用层：为特定应用提供服务（HTTP/FTP/SMTP/DNS）
  • 表示层：数据的表示、压缩、加密
  • 会话层：建立/管理/终止会话
  • 传输层：端到端的可靠/不可靠传输
  • 网络层：分组传送、路由选择
  • 数据链路层：相邻结点间的可靠传输
  • 物理层：在介质上传输比特流

TCP/IP 模型（4 层） ​

应用层 → 传输层 → 网际层 → 网络接口层
1

五层参考模型（教学用） ​

应用层 → 传输层 → 网络层 → 数据链路层 → 物理层
1

OSI vs TCP/IP

  • OSI 先有模型后有协议，TCP/IP 先有协议后有模型
  • OSI 的网络层同时支持无连接和面向连接
  • TCP/IP 的网际层仅支持无连接（IP），传输层同时支持两者（TCP+UDP）

2.4 数据传输过程中的封装与解封 ​

发送方（自上而下封装）：
应用层数据 → +传输层首部=报文段 → +网络层首部=数据报 → +链路层首部尾部=帧 → 比特流

接收方（自下而上解封）：
比特流 → 帧 → 数据报 → 报文段 → 应用层数据

各层 PDU 名称

应用层=报文，传输层=报文段/用户数据报，网络层=分组/数据报，链路层=帧，物理层=比特

三、性能指标 ​

3.1 速率相关 ​

指标含义
带宽网络的最高数据传输速率（b/s）
吞吐量单位时间内实际通过的数据量

3.2 时延 ​

总时延=发送时延+传播时延+处理时延+排队时延
时延类型计算方式说明
发送时延数据长度 / 信道带宽与带宽有关
传播时延信道长度 / 电磁波传播速率与距离有关
处理时延—分析首部、检错等
排队时延—等待输出链路可用

发送时延 vs 传播时延

发送时延是将数据推入链路所需时间（与数据量和带宽有关）；传播时延是电磁波在链路上传播所需时间（与距离和光速有关）。两者完全不同！

3.3 时延带宽积 ​

时延带宽积=传播时延×带宽

表示链路上**"正在传输中"的比特数**，类似于链路的"容量"。

3.4 往返时延 RTT ​

从发送方发送数据开始到收到来自接收方确认的总时间。

3.5 信道利用率 ​

U=DD+RTT

信道利用率不是越高越好，利用率过高会造成严重的时延。
