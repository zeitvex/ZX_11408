# 408 统考计算机网络 (Computer Network) —— 知识库总览

> 本资料库汇集了 408 考研《计算机网络》科目的全部核心知识点，涵盖体系结构、物理层、数据链路层、网络层、传输层和应用层六大板块。

## 📂 理论模块

- **[01 计算机网络体系结构](01_计算机网络体系结构.md)**：网络概念/组成/功能/分类；OSI/TCP-IP/五层模型；性能指标（带宽/时延/吞吐量/RTT）。
- **[02 物理层](02_物理层.md)**：通信基础（信号/编码/调制）；奈奎斯特定理与香农定理；传输介质；物理层设备。
- **[03 数据链路层](03_数据链路层.md)**：封装成帧/透明传输/差错控制；流量控制（停等/GBN/SR）；介质访问控制（CSMA-CD/CSMA-CA）；局域网与以太网。
- **[04 网络层](04_网络层.md)**：IPv4 地址/子网划分/CIDR；ARP/DHCP/ICMP 协议；路由算法（RIP/OSPF/BGP）；IPv6 基础；路由器工作原理。
- **[05 传输层](05_传输层.md)**：UDP 协议；TCP 协议（连接管理/可靠传输/流量控制/拥塞控制）；端口号与复用分用。
- **[06 应用层](06_应用层.md)**：DNS；FTP；电子邮件（SMTP/POP3/IMAP）；HTTP/HTTPS；DHCP（应用层角度）。

## 🎯 提分与回顾

**分值分布**（计网约 25 分）：网络层（IP 与子网划分）与传输层（TCP）几乎必出大题，链路层的滑动窗口是选择题高发区。

**必背速查**

| 主题 | 一句话结论 |
| :--- | :--- |
| 奈奎斯特（无噪声） | $C = 2W\log_2 V$（bps） |
| 香农（有噪声） | $C = W\log_2(1 + S/N)$，$dB = 10\lg(S/N)$ |
| 滑动窗口 | 停等 $W=1$；GBN 发送窗 $\le 2^n-1$；SR 收发窗 $\le 2^{n-1}$ |
| CSMA/CD 最小帧长 | $2\tau \times$ 数据率，以太网为 64 B |
| 子网划分 | 主机号全 0 为网络号、全 1 为广播，可用主机数 $2^n-2$ |
| TCP 三次握手 | 第三次握手可携带数据，前两次不可 |
| TCP 拥塞控制 | 慢开始（指数）→ 拥塞避免（线性）；超时则 `ssthresh` 减半、`cwnd=1` |
| 各层设备 | 物理层中继器/集线器；链路层网桥/交换机；网络层路由器 |

**高频易错**

1. 传播时延只与**距离和速度**有关，与带宽无关；发送时延才与带宽有关。
2. ARP 工作在**同一局域网内**，跨网段解析的是下一跳路由器的 MAC。
3. 交换机隔离**冲突域**但不隔离广播域，路由器两者都隔离。
4. TCP 是面向字节流的，seq 编号以**字节**计，不是报文段计。
5. FTP 用两个连接：控制连接 21 端口全程保持，数据连接 20 端口用完即断。
6. TCP 四次挥手后主动方需等待 $2MSL$，这是为了让最后的 ACK 可靠到达。
