三、计算题核心套路 ​

套路一：时延计算 ​

总时延=发送时延+传播时延+处理时延+排队时延发送时延=数据量带宽，传播时延=距离传播速率

套路二：子网划分 ​

  1. 确定子网数量和每子网主机数
  2. 计算需要的子网位数和主机位数
  3. 写出子网掩码
  4. 计算各子网：网络地址、广播地址、可用主机范围

套路三：信道利用率 ​

U=TDTD+RTT+TA≈TDTD+RTT

停等协议：U=11+2a，其中 a=传播时延发送时延

GBN/SR：U=W1+2a（W 为窗口大小，当 W<1+2a 时）

套路四：拥塞控制窗口变化 ​

按 RTT 逐步画出 cwnd 变化曲线：

  • 慢开始阶段：1→2→4→8→...（指数增长）
  • 拥塞避免阶段：+1/RTT（线性增长）
  • 超时事件：ssthresh=cwnd/2, cwnd=1
  • 3 个重复ACK：ssthresh=cwnd/2, cwnd=ssthresh

四、易错辨析 ​

易错点正确理解
"TCP 是可靠的所以不会丢包"❌ TCP 通过重传机制补救丢包，不是不丢包
"UDP 不做校验"❌ UDP 有校验和字段，只是校验出错后直接丢弃
"路由器隔离冲突域"❌ 交换机和路由器都能隔离冲突域，路由器还能隔离广播域
"集线器工作在数据链路层"❌ 集线器工作在物理层
"ARP 是数据链路层协议"❌ 考研中一般认为 ARP 属于网络层
"TCP 三次握手第三次可以不发"❌ 必须发，否则服务器无法确认客户端收到了 SYN+ACK
"全双工需要4条信道"❌ 全双工需要2条信道（每个方向各 1 条）
"RIP 最大跳数16"❌ RIP 最大跳数是 15，16 跳表示不可达
"CSMA/CD 用于无线网"❌ CSMA/CD 用于有线以太网，CSMA/CA 用于无线
"HTTP 是有状态的"❌ HTTP 是无状态协议，用 Cookie 维持状态

五、重要头部字段与单位（常考陷阱） ​

单位极易混淆

408 考研中，IP 和 TCP 报文段的长度单位是高频坑点。

字段长度单位备注
IP 首部长度4 字节值为 5 代表 20 字节
IP 总长度1 字节实际数据报总长度
IP 片偏移8 字节必须是 8 的倍数（除最后一片）
TCP 数据偏移4 字节实际即 TCP 首部长度
以太网帧最小长度64 字节不含前导码

七、跨章节联系 ​

联系说明
数据链路层 ↔ 传输层流量控制思想相通（滑动窗口）
网络层 ↔ 数据链路层ARP 协议连接两层（IP→MAC）
传输层 ↔ 应用层TCP/UDP 为应用层协议提供服务
物理层 ↔ 计算机组成编码调制、信号传输与计组数据表示相关
网络层 ↔ 操作系统路由算法（Dijkstra）与 OS 调度算法思想相通

冲刺阶段建议

  1. TCP 三次握手/四次挥手和拥塞控制的状态转换图必须能手画
  2. 子网划分计算做到30 秒内出答案
  3. 协议端口号表死记硬背，选择题必考
  4. GBN 和 SR 的窗口大小约束条件不要混淆
