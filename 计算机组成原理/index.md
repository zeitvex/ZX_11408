## 🎯 提分与回顾

**分值分布**（计组约 45 分）：存储系统（Cache + 虚存）与中央处理器（数据通路 + 流水线）是大题主战场，数据表示是选择题密集区。

**必背速查**

| 主题 | 一句话结论 |
| :--- | :--- |
| 补码表示范围（$n$ 位） | $[-2^{n-1},\ 2^{n-1}-1]$，比原码多一个负数 |
| 补码加减溢出判别 | 双符号位不同即溢出；或最高两位进位不同 |
| IEEE 754 单精度 | 1 + 8 + 23，偏置 127，真值 $(-1)^S(1.M)\times 2^{E-127}$ |
| Cache 命中时间 | $T = H\cdot T_c + (1-H)\cdot T_m$（同时访问则不同） |
| Cache 三种映射 | 直接（无需替换算法）、全相联、组相联 |
| 流水线 CPU 周期 | 取**最长**段的时间；加速比 $= T_{串}/T_{流}$ |
| 中断响应时机 | 每条指令**执行结束**后统一查询 |
| DMA 与中断的区别 | DMA 传输数据不经 CPU，只在**块传完**后中断一次 |

**高频易错**

1. 主存地址划分：**先按块**再按块内地址；组相联要先定组号再比标记。
2. 字长、存储字长、机器字长三者不同，题目给的是哪个要看清。
3. 页式虚存中，**页表项**存的是页框号，不是物理地址。
4. 流水线的"吞吐率"分最大吞吐率与实际吞吐率，别混用。
5. 中断隐指令由**硬件**完成，不是程序员写的指令。
