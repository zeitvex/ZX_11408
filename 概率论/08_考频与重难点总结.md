| 分布 | 记号 | $E(X)$ | $D(X)$ |

| 0-1 分布 | $B(1,p)$ | $p$ | $p(1-p)$ |

## 三、典型大题套路

### 套路一：求分布

1. 确定随机变量类型（离散/连续）
2. 离散型：列出所有取值和对应概率
3. 连续型：用分布函数法 $F_Y(y) = P(Y \leq y)$，再求导得密度

### 套路二：求数字特征

1. 直接用公式 $E(g(X))$ 或 $E(g(X,Y))$
2. 利用性质：$D(X) = E(X^2) - [E(X)]^2$
3. 利用已知分布的期望方差表

### 套路三：最大似然估计

1. 写似然函数 $L = \prod f(x_i;\theta)$
2. 取对数 $\ln L$
3. 对 $\theta$ 求导令 $= 0$
4. 解出 $\hat{\theta}$
5. 检验无偏性：$E(\hat{\theta}) = \theta$？

### 套路四：矩估计

1. $E(X) = g(\theta)$，令 $\bar{X} = g(\hat{\theta})$
2. 若两个参数：再用 $E(X^2) = h(\theta_1, \theta_2)$，令 $A_2 = h(\hat{\theta}_1, \hat{\theta}_2)$
3. 解方程组

## 四、易错辨析

| 易错点 | 正确理解 |
|--------|---------|
| "$P(A) = 0$ 则 A 不可能发生" | ❌ 连续型中 $P(X=a) = 0$ 但 a 可能取到 |
| "不相关等于独立" | ❌ 仅**二维正态**时不相关 $\Leftrightarrow$ 独立 |
| "$S^2$ 除以 n" | ❌ 样本方差除以 $n-1$（为了无偏） |
| "MLE 一定无偏" | ❌ MLE 不一定是无偏估计 |
| "$E(XY) = E(X)E(Y)$ 总成立" | ❌ 仅在**独立**或**不相关**时成立 |
| "频率等于概率" | ❌ 频率**依概率收敛于**概率（大数定律） |
| "方差为 0 表示随机变量恒为常数" | ✅ $D(X) = 0 \Leftrightarrow P(X = E(X)) = 1$ |

---

> [!WARNING] 冲刺建议
> 1. **常见分布的期望方差表必须死记硬背**
> 2. MLE 和矩估计的步骤**流程化训练**
> 3. 二维正态分布的独立性判定（$\rho = 0$）是高频考点
> 4. 切比雪夫不等式的应用需要灵活变通
