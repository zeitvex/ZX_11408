## 🎯 提分与回顾

**分值分布**（概率约 34 分）：两道大题常为"二维随机变量函数的分布 / 数字特征"与"参数估计"，数理统计部分性价比高。

**常见分布速查**

| 分布 | $E(X)$ | $D(X)$ |
| :--- | :--- | :--- |
| $0\text{-}1(p)$ | $p$ | $p(1-p)$ |
| $B(n,p)$ | $np$ | $np(1-p)$ |
| $P(\lambda)$ | $\lambda$ | $\lambda$ |
| $G(p)$ 几何 | $1/p$ | $(1-p)/p^2$ |
| $U(a,b)$ | $(a+b)/2$ | $(b-a)^2/12$ |
| $E(\lambda)$ 指数 | $1/\lambda$ | $1/\lambda^2$ |
| $N(\mu,\sigma^2)$ | $\mu$ | $\sigma^2$ |
| $\chi^2(n)$ | $n$ | $2n$ |

**必背结论**

| 主题 | 一句话结论 |
| :--- | :--- |
| 方差公式 | $D(X)=E(X^2)-[E(X)]^2$ |
| 协方差 | $\operatorname{Cov}(X,Y)=E(XY)-E(X)E(Y)$ |
| 和的方差 | $D(X\pm Y)=D(X)+D(Y)\pm 2\operatorname{Cov}(X,Y)$ |
| 独立与不相关 | 独立 $\Rightarrow$ 不相关；反之**仅正态时**成立 |
| 三大抽样分布 | $\overline X\sim N(\mu,\sigma^2/n)$，$(n-1)S^2/\sigma^2\sim\chi^2(n-1)$，且二者独立 |
| 最大似然 | 先写 $L(\theta)$，再取 $\ln$ 求导；注意**均匀分布**等要用单调性而非求导 |

**高频易错**

1. 分布函数 $F(x)$ 是**右连续**的，且 $F(-\infty)=0,F(+\infty)=1$。
2. 求二维函数分布时，先画出积分区域再定限，"卷积公式"只在独立时可用。
3. 不相关只说明**线性**无关，$\rho=0$ 不等于独立。
4. $E(XY)=E(X)E(Y)$ 只在不相关（含独立）时成立。
5. 无偏性判断的是 $E(\hat\theta)=\theta$，样本方差用 $n-1$ 才无偏。
6. 假设检验中"接受 $H_0$"只是**证据不足以拒绝**，不等于 $H_0$ 为真。
