# 06 数理统计基本概念

> 本章是数理统计的基础，重点掌握三大抽样分布及其性质。

## 一、总体与样本

- **总体**：研究对象的全体
- **样本**：从总体中抽取的 $n$ 个个体 $X_1, X_2, \cdots, X_n$
- **简单随机样本**：独立同分布

## 二、统计量

统计量是样本的函数，**不含未知参数**。

### 常用统计量

| 统计量 | 公式 |
|--------|------|
| 样本均值 | $\bar{X} = \frac{1}{n}\sum_{i=1}^{n} X_i$ |
| 样本方差 | $S^2 = \frac{1}{n-1}\sum_{i=1}^{n}(X_i - \bar{X})^2$ |
| 样本标准差 | $S = \sqrt{S^2}$ |
| 样本 k 阶原点矩 | $A_k = \frac{1}{n}\sum_{i=1}^{n} X_i^k$ |
| 样本 k 阶中心矩 | $B_k = \frac{1}{n}\sum_{i=1}^{n}(X_i - \bar{X})^k$ |

> [!WARNING] 样本方差除以 n-1
> $S^2$ 的分母是 $n-1$（而非 $n$），这是为了保证 $E(S^2) = \sigma^2$（**无偏性**）。

## 三、三大抽样分布

### 3.1 $\chi^2$ 分布

$\chi^2 = X_1^2 + X_2^2 + \cdots + X_n^2$，其中 $X_i \sim N(0,1)$ 独立，则 $\chi^2 \sim \chi^2(n)$

性质：
- $E(\chi^2) = n$，$D(\chi^2) = 2n$
- $\chi_1^2 + \chi_2^2 \sim \chi^2(n_1 + n_2)$（可加性）

### 3.2 $t$ 分布

$$t = \frac{X}{\sqrt{Y/n}}，\quad X \sim N(0,1), Y \sim \chi^2(n), X \perp Y$$

性质：
- 密度函数关于 0 对称
- $n$ 充分大时近似 $N(0,1)$
- $t_{1-\alpha}(n) = -t_\alpha(n)$

### 3.3 $F$ 分布

$$F = \frac{X/n_1}{Y/n_2}，\quad X \sim \chi^2(n_1), Y \sim \chi^2(n_2), X \perp Y$$

性质：
- $\frac{1}{F} \sim F(n_2, n_1)$
- $F_{1-\alpha}(n_1, n_2) = \frac{1}{F_\alpha(n_2, n_1)}$

## 四、正态总体的抽样分布

设 $X_1, \cdots, X_n$ 来自 $N(\mu, \sigma^2)$，则：

| 结论 | 分布 |
|------|------|
| $\bar{X} \sim N(\mu, \sigma^2/n)$ | 正态 |
| $\frac{(n-1)S^2}{\sigma^2} \sim \chi^2(n-1)$ | 卡方 |
| $\frac{\bar{X} - \mu}{S/\sqrt{n}} \sim t(n-1)$ | t 分布 |
| $\bar{X}$ 与 $S^2$ **独立** | — |

> [!IMPORTANT] 上述四个结论是假设检验和参数估计的理论基础。
