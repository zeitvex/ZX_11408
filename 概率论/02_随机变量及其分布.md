# 02 随机变量及其分布

> 随机变量是概率论的核心研究对象。本章重点在于掌握“分布函数”及其与“概率密度/分布律”的对应关系。

## 一、 核心概念

### 1.1 分布函数 $F(x)$ (通用)
定义：$F(x) = P(X \le x)$。
> [!IMPORTANT] $F(x)$ 的三大性质 (判定准则)
> 1. **单调不减**：$x_1 < x_2 \implies F(x_1) \le F(x_2)$。
> 2. **有界性**：$F(-\infty) = 0, F(+\infty) = 1$。
> 3. **右连续**：$\lim_{x \to x_0^+} F(x) = F(x_0)$。

### 1.2 离散型 vs 连续型
- **离散型**：用分布律 $P(X=x_i) = p_i$ 描述。满足 $\sum p_i = 1$。
- **连续型**：用概率密度 $f(x)$ 描述。满足 $\int_{-\infty}^{+\infty} f(x)dx = 1$。
  - $F(x) = \int_{-\infty}^x f(t)dt$。
  - $P(x_1 < X \le x_2) = F(x_2) - F(x_1) = \int_{x_1}^{x_2} f(x)dx$。

## 二、 常用分布速查表

| 分布名称 | 符号 | 概率密度/分布律 | 期望 $E(X)$ | 方差 $D(X)$ |
| :--- | :--- | :--- | :--- | :--- |
| **0-1 分布** | $B(1, p)$ | $P=p^k q^{1-k}$ | $p$ | $pq$ |
| **二项分布** | $B(n, p)$ | $C_n^k p^k q^{n-k}$ | $np$ | $npq$ |
| **泊松分布** | $P(\lambda)$ | $\frac{e^{-\lambda} \lambda^k}{k!}$ | $\lambda$ | $\lambda$ |
| **均匀分布** | $U(a, b)$ | $\frac{1}{b-a}, a < x < b$ | $\frac{a+b}{2}$ | $\frac{(b-a)^2}{12}$ |
| **指数分布** | $E(\lambda)$ | $\lambda e^{-\lambda x}, x > 0$ | $1/\lambda$ | $1/\lambda^2$ |
| **正态分布** | $N(\mu, \sigma^2)$ | $\frac{1}{\sqrt{2\pi}\sigma} e^{-\frac{(x-\mu)^2}{2\sigma^2}}$ | $\mu$ | $\sigma^2$ |

> [!TIP] 指数分布的“无记忆性”
> $P(X > s+t \mid X > s) = P(X > t)$。常用于排队论、寿命测试等建模。

## 三、 随机变量函数的分布 $Y = g(X)$

1. **离散型**：直接代入取值，合并相同结果。
2. **连续型**：
   - **分布函数法 (万能)**：$F_Y(y) = P(g(X) \le y)$，化简为 $X$ 的区间再积分。
   - **公式法**：若 $g(x)$ 严格单调，则 $f_Y(y) = f_X[h(y)] \cdot |h'(y)|$，其中 $h(y)$ 为反函数。
