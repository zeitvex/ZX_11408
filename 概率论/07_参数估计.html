07 参数估计 ​

参数估计是概率论大题的重要考点，尤其是最大似然估计法。

一、点估计 ​

1.1 矩估计 ​

用样本矩代替总体矩，建立方程求解未知参数。

步骤：

  1. 计算总体的 1 阶矩 E(X)=g1(θ)，2 阶矩 E(X2)=g2(θ)（如需要）
  2. 令 X¯=g1(θ^)（样本均值 = 总体均值）
  3. 若有两个参数，再令 A2=g2(θ^1,θ^2)
  4. 解方程得 θ^

1.2 最大似然估计 (MLE) ​

离散型 ​

似然函数：L(θ)=∏i=1np(xi;θ)

连续型 ​

似然函数：L(θ)=∏i=1nf(xi;θ)

求解步骤 ​

  1. 写出似然函数 L(θ)
  2. 取对数得 ln⁡L(θ)
  3. 求导令 dln⁡Ldθ=0
  4. 解方程得最大似然估计值 θ^

MLE 的不变性

若 θ^ 是 θ 的 MLE，则 g(θ^) 是 g(θ) 的 MLE。

特殊情况

当似然函数单调时（如均匀分布），不能令导数为零，需要通过函数的单调性直接求极值。

二、估计量的评价标准 ​

2.1 无偏性 ​

E(θ^)=θ，则 θ^ 是 θ 的无偏估计。

  • X¯ 是 μ 的无偏估计
  • S2 是 σ2 的无偏估计
  • S2=1n−1∑(Xi−X¯)2 是无偏的，1n∑(Xi−X¯)2 不是无偏的

2.2 有效性 ​

方差更小的无偏估计更有效。

2.3 一致性（相合性） ​

θ^n→Pθ（n→∞），则 θ^n 是 θ 的一致（相合）估计量。
