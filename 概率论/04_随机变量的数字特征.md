# 04 随机变量的数字特征

> 数字特征是概率论计算的核心工具。期望和方差的性质必须熟练掌握。

## 一、数学期望

### 1.1 离散型

$$E(X) = \sum_{i} x_i p_i$$

### 1.2 连续型

$$E(X) = \int_{-\infty}^{+\infty} x f(x)\,dx$$

### 1.3 随机变量函数的期望

$$E(g(X)) = \begin{cases} \sum_i g(x_i)p_i & \text{离散型} \\ \int_{-\infty}^{+\infty} g(x)f(x)\,dx & \text{连续型} \end{cases}$$

$$E(g(X,Y)) = \int_{-\infty}^{+\infty}\int_{-\infty}^{+\infty} g(x,y)f(x,y)\,dx\,dy$$

### 1.4 期望的性质

- $E(C) = C$
- $E(aX + b) = aE(X) + b$
- $E(X + Y) = E(X) + E(Y)$（**无需独立**）
- $X, Y$ 独立时：$E(XY) = E(X)E(Y)$

## 二、方差

$$D(X) = E[(X - E(X))^2] = E(X^2) - [E(X)]^2$$

### 2.1 方差的性质

- $D(C) = 0$
- $D(aX + b) = a^2 D(X)$
- $D(X + Y) = D(X) + D(Y) + 2\text{Cov}(X,Y)$
- $X, Y$ 独立时：$D(X + Y) = D(X) + D(Y)$

> [!IMPORTANT] 方差计算公式
> $D(X) = E(X^2) - [E(X)]^2$ 是最常用的计算方式。

## 三、协方差与相关系数

### 3.1 协方差

$$\text{Cov}(X, Y) = E[(X - E(X))(Y - E(Y))] = E(XY) - E(X)E(Y)$$

性质：
- $\text{Cov}(X, X) = D(X)$
- $\text{Cov}(X, Y) = \text{Cov}(Y, X)$
- $\text{Cov}(aX, bY) = ab\,\text{Cov}(X, Y)$
- $\text{Cov}(X+Y, Z) = \text{Cov}(X,Z) + \text{Cov}(Y,Z)$

### 3.2 相关系数

$$\rho_{XY} = \frac{\text{Cov}(X,Y)}{\sqrt{D(X)}\sqrt{D(Y)}}$$

- $|\rho| \leq 1$
- $|\rho| = 1 \Leftrightarrow$ $X$ 与 $Y$ 之间有**线性关系**
- $\rho = 0$ 称为 $X, Y$ **不相关**

### 3.3 不相关 vs 独立

- 独立 → 不相关（**必然成立**）
- 不相关 → 独立（**一般不成立**，二维正态除外）

> [!WARNING] 不相关 ≠ 独立
> 不相关仅表示没有**线性**关系，可能存在非线性关系。

## 四、常见分布的期望与方差速查

| 分布 | $E(X)$ | $D(X)$ |
|------|--------|--------|
| $B(1,p)$ | $p$ | $p(1-p)$ |
| $B(n,p)$ | $np$ | $np(1-p)$ |
| $P(\lambda)$ | $\lambda$ | $\lambda$ |
| $U(a,b)$ | $\frac{a+b}{2}$ | $\frac{(b-a)^2}{12}$ |
| $E(\lambda)$ | $\frac{1}{\lambda}$ | $\frac{1}{\lambda^2}$ |
| $N(\mu,\sigma^2)$ | $\mu$ | $\sigma^2$ |
| $\chi^2(n)$ | $n$ | $2n$ |
| $t(n)$ | $0$ | $\frac{n}{n-2}$ |
