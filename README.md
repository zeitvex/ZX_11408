# ZX_11408 知识库项目

> **面向 计算机考研 (408 + 数一) 的知识库。**

本仓库旨在构建一个系统、专业且易于快速回忆的考研复习体系。基于 **VitePress**
驱动，支持 LaTeX 公式渲染、Gfm 标注语法，并针对移动端与 Web 端进行了深度优化。

## ✍️ 写作与排版约定

为保证全库风格一致、渲染正确，新增或修改内容时请遵守以下约定。

### 页面结构

每个章节页只有**一个一级标题**，层级与编号固定如下：

```markdown
# 科目·序号 章节名        ← 全页唯一，不编号
## 考纲内容               ← 该章考纲要点，一条一行
## 一、大节               ← 正文大节：中文数字 + 顿号
### 1. 小节               ← 阿拉伯数字 + 点 + 空格
#### 子目                 ← 默认不编号；若同级并列且需排序，同样用 `N. `
##### 更细                ← 同上
```

编号规则只有三条，照做即可保持全库一致：

| 规则 | 说明 |
| :--- | :--- |
| **同一父节下，要么都编号，要么都不编号** | 不允许一部分带号、一部分不带 |
| **正文大节编号，附录性小节不编号** | 附录指「核心公式速查 / 易错辨析 / 重难点提示 / 考点汇总 / 大题解题套路 / 题目整理 / 番外」，一律置于文末 |
| **编号连续，不跳号** | 删改内容后要重排，不能留下 `一、二、四` |

其它约定：

- 分隔符统一：H2 用 `一、`，H3 及以下用 `1. `（点后一个半角空格）。
  不使用 `1.1`、`（1）`、`1)`、`一.` 等写法。
- 标题前缀 `*` 表示**超纲或选读**内容，例如 `#### *光盘存储器`，保持不编号。

### 数学公式

- 行内公式用 `$...$`，**定界符内侧不能有空格**：`$x$` 正确，`$ x$` 与 `$x $` 都不会渲染。
- 公式**不能跨行断开**，`$` 必须在同一行内配对。
- 表格单元格内避免出现裸的 `|`：绝对值/行列式写 `\lvert A\rvert`，条件/增广写 `\mid`。
  注意 `\|` 在 LaTeX 中是范数 ‖，不能拿来当竖线转义。
- 多行公式（如 `\begin{cases}`）一律用独立的 `$$` 块。

### 强调层级

正文使用两级强调，请勿混用或互相替换：

| 写法 | 含义 | 示例 |
| :--- | :--- | :--- |
| `**加粗**` | 关键**术语**、名词 | **进程**是资源分配的基本单位 |
| `<u>下划线</u>` | 需要记住的**论断**、整句要点 | <u>阻塞态不能直接转为运行态</u> |

## 🚀 深度部署流程 (1Panel + GitHub Actions)

本项目的部署采用 **“源码托管-云端编译-静态分发”** 的模式，实现推送即上线的自动化流程。

### 1. 主机端 (Local Machine)

这是您的写作环境，日常操作如下：

- **修改内容**：在本地 IDE (如 VS Code) 中编辑 Markdown 文件。
- **本地验证**：运行 `npm run dev` 查看效果，运行 `npm run build` 确保无死链。
- **推送更新**：执行 Git 三板斧：
  ```bash
  git add .
  git commit -m "feat: 补充 xxx 章节知识点"
  git push origin main
  ```

### 2. GitHub 端 (GitHub Actions)

当 `main` 分支接收到推送时，会自动触发 `.github/workflows/deploy.yml` 工作流：

- **环境搭建**：初始化 Node.js 环境，安装依赖。
- **静态构建**：执行 `npm run build` 生成 `.vitepress/dist` 目录。
- **分支分发**：将编译后的静态网页强制推送到仓库的 `gh-pages` 分支。
- **指令下发**：工作流通过 SSH 连接至您的 1Panel 服务器。

### 3. 服务器端 (1Panel Server)

服务器接收到 GitHub 的 SSH 指令后，在静态网站目录下执行同步：

- **目录定位**：进入 1Panel 创建的静态网站目录 (如 `/opt/1panel/apps/.../yoursite.com/index`)。
- **增量拉取**：执行 `git fetch --all` 拉取远程最新的 `gh-pages` 分支。
- **强制覆盖**：执行 `git reset --hard origin/gh-pages`，将网站内容瞬间更新为最新编译结果。
- **即时生效**：由于是 OpenResty 托管的静态站点，文件替换后无需重启服务即可访问。
