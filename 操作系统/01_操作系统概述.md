# 01 操作系统概述

> 本章是操作系统的入门章节，主要考查操作系统的基本概念、特征、功能以及运行环境。以选择题为主，但系统调用与中断机制是理解后续所有章节的基础。

## 一、操作系统的概念

计算机系统自下而上可大致分为：**硬件 → 操作系统 → 应用程序 → 用户**。

操作系统 (Operating System) 是指**控制和管理整个计算机系统的硬件与软件资源，合理地组织、调度计算机的工作与资源的分配**，进而为用户和其他软件**提供方便接口与环境的程序集合**，操作系统是计算机系统中**最基本的系统软件**。

## 二、操作系统的特征

操作系统有四个基本特征，其中**并发和共享是两个最基本的特征**，二者互为存在条件。

### 2.1 并发 (Concurrence)

并发是指**两个或多个事件在同一时间间隔内发生**。

- **并发**：同一时间**间隔**（一段时间内），宏观上多道程序同时执行，微观上分时交替执行
- **并行**：同一时**刻**，需要多处理器硬件支持

> [!IMPORTANT] 并发 vs 并行
> 并发是"一段时间内"的宏观同时，并行是"同一时刻"的真正同时。单 CPU 系统中各进程只能并发执行，不能并行。

### 2.2 共享 (Sharing)

资源共享是指**系统中的资源可供内存中多个并发执行的进程共同使用**。

- **互斥共享**：一段时间内**只允许一个进程访问**该资源（临界资源/独占资源）
- **同时访问**：宏观上允许多个进程"同时"访问（微观上交替访问），如磁盘

### 2.3 虚拟 (Virtual)

虚拟是指**把一个物理上的实体变为若干逻辑上的对应物**。

- **虚拟处理器**（时分复用）：利用多道程序设计技术，将一个物理 CPU 虚拟为多个逻辑 CPU
- **虚拟存储器**（空分复用）：从逻辑上扩充存储器容量
- **虚拟设备**：将一台物理 I/O 设备虚拟为多台逻辑设备（如 SPOOLing 技术）

### 2.4 异步 (Asynchronism)

多道程序环境下，进程的执行**不是一贯到底的**，而是走走停停、以**不可预知**的速度向前推进。

> [!WARNING] 异步性要求
> 只要**运行环境相同**，操作系统就必须保证多次运行进程后都能获得**相同的结果**。

## 三、操作系统的目标和功能

### 3.1 系统资源的管理者

| 管理功能 | 主要内容 |
|---------|---------|
| **处理机管理** | 进程控制、进程同步、进程通信、死锁处理、处理机调度 |
| **存储器管理** | 内存分配与回收、地址映射、内存保护与共享、内存扩充 |
| **文件管理** | 文件存储空间管理、目录管理、文件读写管理和保护 |
| **设备管理** | 缓冲管理、设备分配和回收、设备处理、虚拟设备 |

### 3.2 用户与硬件之间的接口

- **命令接口**：
  - 联机命令接口（交互式）：用户通过终端输入命令，适用于分时/实时系统
  - 脱机命令接口（批处理）：用户事先编写作业操作说明书，如 `.bat` 文件
- **程序接口**：由**系统调用**（广义指令）组成，用户只能通过程序间接使用

> [!IMPORTANT] GUI 不属于操作系统
> 图形接口最终通过调用**程序接口**（系统调用）实现。严格来说 GUI 不是操作系统的一部分，但 GUI 调用的系统调用是。

### 3.3 扩充机器

没有任何软件支持的计算机称为**裸机**。覆盖了操作系统软件的机器称为**扩充机器**或**虚拟机**。

## 四、操作系统的发展与分类

### 4.1 手工操作阶段

- 无操作系统
- 用户独占全机，资源利用率低
- CPU 等待手工操作，CPU 利用率低

### 4.2 批处理阶段

**单道批处理系统**：

- 特征：自动性、顺序性、单道性
- 内存中仅一道程序，CPU 遇 I/O 请求时等待

**多道批处理系统**：

- 多道程序**同时驻留内存**，**宏观并行、微观串行**
- 优点：资源利用率高、系统吞吐量大
- 缺点：用户响应时间长、不提供人机交互

### 4.3 分时操作系统

- 多用户通过终端共享主机
- **时间片轮转**方式为各用户服务
- 特征：同时性、交互性、独立性、及时性

### 4.4 实时操作系统

- **硬实时**：必须绝对在规定时刻完成（如飞行控制）
- **软实时**：偶尔违反时限不会永久损害（如订票系统）
- 主要特点：**及时性和可靠性**

## 五、操作系统的运行环境

### 5.1 运行机制

- **特权指令**：不允许用户直接使用的指令（如 I/O 指令、置中断指令）
- **非特权指令**：用户程序可以使用的指令

两种处理器状态：

| | 核心态（管态） | 用户态（目态） |
|---|---|---|
| 可执行指令 | 特权 + 非特权 | 仅非特权 |
| 运行程序 | 系统内核程序 | 用户应用程序 |

### 5.2 内核的功能

内核是计算机上配置的**底层软件**，是计算机功能的延伸：

1. **时钟管理**：提供标准系统时间，实现进程切换
2. **中断机制**：操作系统各项操作的基础，现代操作系统是**靠中断驱动的软件**
3. **原语**：最接近硬件、具有原子性的操作，不可被中断
4. **系统控制的数据结构及处理**：进程管理、存储器管理、设备管理

### 5.3 中断和异常

- **中断（外中断）**：来自 CPU 执行**指令以外**的事件（如 I/O 中断、时钟中断）
- **异常（内中断）**：源自 CPU 执行**指令内部**的事件（如非法操作码、缺页、陷入指令）

> [!IMPORTANT] 用户态 → 核心态的唯一途径
> CPU 运行用户程序时，进入核心态的**唯一途径**是通过**中断或异常**。核心态 → 用户态由特权指令（中断返回指令）实现。

中断处理流程：关中断 → 保存断点（硬件） → 引出中断服务程序 → 保存现场和屏蔽字 → 开中断 → 执行中断服务 → 关中断 → 恢复现场和屏蔽字 → 开中断、中断返回

### 5.4 系统调用

系统调用是指**用户在程序中调用操作系统所提供的一些子功能**，是特殊的公共子程序，**运行在核心态**。

系统调用按功能分为：

| 类型 | 功能举例 |
|------|---------|
| 设备管理 | 设备请求/释放/启动 |
| 文件管理 | 文件读/写/创建/删除 |
| 进程控制 | 进程创建/撤销/阻塞/唤醒 |
| 进程通信 | 消息传递/信号传递 |
| 内存管理 | 内存分配/回收 |

> [!WARNING] 访管指令 (trap)
> 用户通过**陷入指令**（访管指令）来调用系统调用。访管指令**只能在用户态使用**，它本身**不是特权指令**。

## 六、大内核与微内核

| | 大内核 | 微内核 |
|---|---|---|
| 设计思想 | 操作系统主要功能模块都在内核中 | 只保留最基本的功能在内核 |
| 优点 | **高性能** | 结构清晰，方便维护 |
| 缺点 | 内核庞大，结构混乱，难以维护 | 需频繁切换态，**性能较低** |
