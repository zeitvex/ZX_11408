## 🎯 提分与回顾

**分值分布**（操作系统约 35 分）：进程管理（同步互斥 + 死锁）与内存管理（虚存 + 置换算法）是绝对重心，大题多出于此。

**必背速查**

| 主题 | 一句话结论 |
| :--- | :--- |
| 进程 vs 线程 | 进程是**资源分配**单位，线程是**调度**单位 |
| 五状态转换 | 就绪→运行（调度）、运行→就绪（时间片到）、运行→阻塞（**主动**）、阻塞→就绪（**被动**） |
| 阻塞不能直接到运行 | 也不存在就绪→阻塞 |
| PV 操作 | 互斥信号量初值 1；同步看"前趋图"，一条弧一个信号量 |
| 死锁四条件 | 互斥、不剥夺、请求并保持、循环等待（**破坏任一**即可预防） |
| 银行家算法 | 属于死锁**避免**，不是预防也不是检测 |
| 页面置换 | OPT 最优不可实现；LRU 需硬件支持；**FIFO 会有 Belady 异常** |
| 磁盘访问时间 | 寻道 + 旋转延迟 + 传输，旋转延迟平均为半圈 |

**高频易错**

1. 分页的页大小由**系统**决定，分段的段长由**用户/程序**决定。
2. 请求分页中，缺页中断属于**内中断（异常）**，且一条指令可能产生多次。
3. 快表 TLB 命中时不访问页表；两级页表命中 TLB 仍只需一次访存取数据。
4. SPOOLing 把独占设备改造为**共享**设备，需要磁盘作输入/输出井。
5. 时间片轮转的时间片过大会退化为 **FCFS**。
6. 银行家算法判断的是"是否处于**安全状态**"，不安全 ≠ 一定死锁。
