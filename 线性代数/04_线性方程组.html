04 线性方程组 ​

线性方程组是线性代数的核心应用，也是考研大题的常客。本章重点：解的判定、解的结构。

一、齐次线性方程组 Ax=0 ​

1.1 解的判定 ​

  • 有非零解 ⇔ r(A)<n（n 为未知数个数）
  • 只有零解 ⇔ r(A)=n
  • 方程数 m < 未知数 n 时，必有非零解

1.2 解的结构 ​

  • 基础解系：齐次方程组解空间的一组基
  • 基础解系包含 n−r(A) 个线性无关的解向量
  • 通解 = k1ξ1+k2ξ2+⋯+kn−rξn−r

求基础解系

将系数矩阵化为行最简形 → 找自由变量 → 分别令一个自由变量为 1 其余为 0 → 解出对应解向量

二、非齐次线性方程组 Ax=b ​

2.1 解的判定 ​

条件解的情况
r(A)≠r(A¯)无解
r(A)=r(A¯)=n唯一解
r(A)=r(A¯)<n无穷多解

其中 A¯=(A|b) 是增广矩阵。

2.2 解的结构 ​

设 η∗ 是一个特解，ξ1,⋯,ξn−r 是对应齐次方程组的基础解系，则通解为：

x=η∗+k1ξ1+k2ξ2+⋯+kn−rξn−r

非齐次通解 = 特解 + 齐次通解

这是线性方程组最重要的结论，也是大题常考结构。

2.3 解的性质 ​

  • 两个特解之差是对应齐次方程组的解
  • 特解的线性组合：若 k1+k2+⋯+ks=1，则 k1η1+⋯+ksηs 仍是特解
  • 若 k1+k2+⋯+ks=0，则是齐次方程组的解

三、方程组的公共解与同解 ​

  • 公共解：同时满足两个方程组的解，联立两个方程组求解
  • 同解：两个方程组的解集完全相同 ⇔ 增广矩阵等价

本章考频

  • 解的判定与求解 ★★★★★（大题常考）
  • 解的结构定理 ★★★★★
  • 基础解系 ★★★★★
