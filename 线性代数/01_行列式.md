# 01 行列式

> 行列式是线性代数的计算基础工具，贯穿后续所有章节。除基础性质外，熟练掌握“模型识别”是提速关键。

## 一、 行列式的核心性质

| 性质 | 核心要点 |
| :--- | :--- |
| **转置** | $D^T = D$ (行列地位平等) |
| **互换** | 换行/换列 $\implies$ 变号 |
| **倍乘** | 某行乘 $k \implies$ 结果乘 $k$。注意：$|kA| = k^n|A|$ |
| **倍加** | 某行 $k$ 倍加到另一行 $\implies$ **值不变** (最强消元工具) |
| **零值** | 两行相同、成比例或有一行全为 0 $\implies |D|=0$ |

## 二、 特殊模型与计算技巧

### 2.1 基础模型
- **三角行列式**：主对角线元素之积。
- **副对角线三角**：$(-1)^{\frac{n(n-1)}{2}} \times$ 对角线乘积。
- **范德蒙行列式 (Vandermonde)**：
  $$ V_n = \prod_{1 \le j < i \le n} (x_i - x_j) $$
  *技巧：若题目未直接给出 1 1 1 行，尝试通过“倍加”凑出常数行再提取。*

### 2.2 高阶模型 (Exam Triggers)
- **AB 型 (爪型/箭型)**：对角线为 $a$，其余为 $b$。
  $$ \det(A) = [a + (n-1)b](a-b)^{n-1} $$
- **X 型 (分块扩散型)**：从中心二阶行列式向外扩散相乘。
- **三对角线型 (递推型)**：按最后一列展开，建立递推关系 $a_n + pa_{n-1} + qa_{n-2} = 0$，利用特征方程求解通项。

## 三、 余子式与代数余子式的求和

> [!IMPORTANT] 核心技巧：构造法
> 求解代数余子式之和 $\sum A_{ij}$，通常有三种思路：
> 1. **按行展开**：利用 $\sum a_{ij} A_{ij} = |A|$。
> 2. **换行得零**：利用 $\sum a_{kj} A_{ij} = 0 \ (k \neq i)$。
> 3. **伴随矩阵法**：所有代数余子式之和等于 $\mathbf{1}^T A^* \mathbf{1}$。

## 四、 抽象行列式的性质扩展

1. $|A^*| = |A|^{n-1}$
2. $|A^{-1}| = \frac{1}{|A|}$
3. $|A^T| = |A|$
4. 若 $A$ 与 $B$ 相似 ($A \sim B$)，则 $|A| = |B|$。
5. $|A| = \prod \lambda_i$ (所有特征值之积)。
