# 07 考频与重难点总结

> 线性代数全科核心公式速查、计算题套路及易错辨析。

## 一、考频分布

| 章节 | 选择题 | 大题 | 总占比 |
|------|--------|------|--------|
| 行列式 | ★★★ | 偶尔 | ~8% |
| 矩阵 | ★★★★ | 逆矩阵/秩 | ~18% |
| 向量 | ★★★★ | 线性相关性 | ~15% |

## 二、核心公式速查

### 行列式

- $|kA| = k^n|A|$
- $|AB| = |A| \cdot |B|$
- $|A^{-1}| = |A|^{-1}$
- $|A^*| = |A|^{n-1}$
- $|A^T| = |A|$

### 矩阵

- $AA^* = |A|E$
- $(AB)^{-1} = B^{-1}A^{-1}$
- $(AB)^T = B^TA^T$
- $r(AB) \leq \min(r(A), r(B))$
- $AB = O \Rightarrow r(A) + r(B) \leq n$

### 特征值

- $\sum \lambda_i = tr(A)$
- $\prod \lambda_i = |A|$
- $A^n$ 的特征值为 $\lambda^n$
- $A^{-1}$ 的特征值为 $1/\lambda$
- $A^*$ 的特征值为 $|A|/\lambda$

## 三、大题常见题型

| 题型 | 方法 |
|------|------|
| 求逆矩阵 | $(A\|E) \to (E\|A^{-1})$ 或 $A^{-1} = A^*/\|A\|$ |
| 求基础解系 | 化行最简形 → 自由变量赋值 |
| 特征值与对角化 | 解特征方程 → 求特征向量 → 构造 P |
| 正交对角化 | 特征向量正交化 → 单位化 → 构造 Q |
| 正定性判定 | 特征值全正 / 顺序主子式全正 |
| 用相似求矩阵 | $A = P\Lambda P^{-1}$ |

## 四、易错辨析

| 易错点 | 正确理解 |
|--------|---------|
| "$AB = 0 \Rightarrow A=0$ 或 $B=0$" | ❌ 矩阵乘积为零不能推出因子为零 |
| "$A^2 = A \Rightarrow A=E$ 或 $A=O$" | ❌ 幂等矩阵有很多种 |
| "$r(A) + r(B) = r(A+B)$" | ❌ 只有 $r(A+B) \leq r(A) + r(B)$ |
| "特征值相同则相似" | ❌ 还需要有足够的线性无关特征向量 |
| "可逆矩阵一定正定" | ❌ 可逆只要 $\|A\| \neq 0$，正定要求特征值全正 |
| "正交矩阵行列式=1" | ❌ 正交矩阵行列式为 $\pm 1$ |
| "实对称矩阵特征值可能为复数" | ❌ 实对称矩阵特征值**全为实数** |
