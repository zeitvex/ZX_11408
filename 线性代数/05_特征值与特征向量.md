# 05 特征值与特征向量

> 本章是线性代数**最重要的考试章节**，特征值求解、相似对角化和正交对角化几乎每年必考大题。

## 一、特征值与特征向量的概念

$A\xi = \lambda\xi$（$\xi \neq 0$），则 $\lambda$ 是 $A$ 的**特征值**，$\xi$ 是对应的**特征向量**。

### 1.1 求特征值

解**特征方程**：$|\lambda E - A| = 0$

### 1.2 求特征向量

对每个特征值 $\lambda_i$，解 $(\lambda_i E - A)x = 0$，非零解即为特征向量。

## 二、特征值的性质

- $\lambda_1 + \lambda_2 + \cdots + \lambda_n = tr(A) = a_{11} + a_{22} + \cdots + a_{nn}$（**迹**）
- $\lambda_1 \cdot \lambda_2 \cdots \lambda_n = |A|$
- $A$ 可逆 $\Leftrightarrow$ 所有特征值不为 0

### 特征值变换

| 矩阵 | 特征值 |
|------|--------|
| $A$ | $\lambda$ |
| $kA$ | $k\lambda$ |
| $A^2$ | $\lambda^2$ |
| $A^n$ | $\lambda^n$ |
| $A^{-1}$ | $1/\lambda$ |
| $A^*$ | $\|A\|/\lambda$ |
| $A + kE$ | $\lambda + k$ |
| $f(A)$ | $f(\lambda)$ |

> [!IMPORTANT] 不同特征值对应的特征向量**线性无关**。

## 三、相似矩阵

$P^{-1}AP = B$，则 $A$ 与 $B$ **相似**，记为 $A \sim B$。

### 相似的必要条件

- 相同的特征值
- 相同的秩
- 相同的行列式
- 相同的迹
- 相同的特征多项式

### 相似对角化

$A$ 可对角化 $\Leftrightarrow$ $A$ 有 **n 个线性无关的特征向量**

$\Leftrightarrow$ 每个 $k$ 重特征值 $\lambda_i$ 有 $k$ 个线性无关的特征向量，即 $n - r(\lambda_i E - A) = k$

对角化步骤：
1. 求特征值 $\lambda_1, \lambda_2, \cdots, \lambda_n$
2. 求每个特征值对应的特征向量 $\xi_1, \xi_2, \cdots, \xi_n$
3. 令 $P = (\xi_1, \xi_2, \cdots, \xi_n)$，则 $P^{-1}AP = \Lambda = \text{diag}(\lambda_1, \cdots, \lambda_n)$

## 四、实对称矩阵的正交对角化

### 4.1 实对称矩阵的性质

1. 特征值全为**实数**
2. 不同特征值对应的特征向量**正交**
3. 实对称矩阵**一定可以对角化**
4. 存在**正交矩阵** $Q$ 使得 $Q^TAQ = \Lambda$

### 4.2 正交对角化步骤

1. 求特征值
2. 求特征向量
3. **同一特征值**对应的特征向量若不正交，用 **Schmidt 正交化**
4. 所有特征向量**单位化**
5. 构造正交矩阵 $Q = (\eta_1, \eta_2, \cdots, \eta_n)$

> [!IMPORTANT] 正交对角化是大题核心
> 务必熟练掌握：求特征值 → 求特征向量 → 正交化 → 单位化 → 构造 Q 矩阵。
