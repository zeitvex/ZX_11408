# 02 矩阵

> 矩阵是线性代数的核心，而“秩” (Rank) 是矩阵的灵魂。本章重点在于理解矩阵运算规律与秩的演变。

## 一、 矩阵运算的基本规律

### 1.1 基础运算法则
- **不满足交换律**：$AB \neq BA$ (除非特殊情况，见下文)。
- **满足结合律与分配律**：$A(BC) = (AB)C$；$A(B+C) = AB + AC$。
- **转置律**：$(AB)^T = B^T A^T$；$(A+B)^T = A^T + B^T$。

### 1.2 伴随矩阵 (Adjoint Matrix)
> [!IMPORTANT] 核心公式：$A A^* = A^* A = |A|E$
- $A^{-1} = \frac{1}{|A|} A^*$ (前提 $|A| \neq 0$)
- $(kA)^* = k^{n-1} A^*$
- $|A^*| = |A|^{n-1}$
- $(A^*)^* = |A|^{n-2} A$

## 二、 矩阵的秩 (Rank)

> [!IMPORTANT] 秩的十大金律
> 1. $r(A) = r(A^T) = r(A^T A) = r(AA^T)$
> 2. $r(kA) = r(A) \ (k \neq 0)$
> 3. $r(A+B) \le r(A) + r(B)$
> 4. $r(AB) \le \min\{r(A), r(B)\}$
> 5. **Sylvester 不等式**：$r(A) + r(B) - n \le r(AB)$
> 6. 若 $AB = O \implies r(A) + r(B) \le n$ (必考，常用于判定解空间)
> 7. $r(A^*) = \begin{cases} n, & r(A) = n \\ 1, & r(A) = n-1 \\ 0, & r(A) < n-1 \end{cases}$
> 8. 初等变换不改变矩阵的秩。
> 9. 矩阵可逆 $\iff$ 满秩 ($r(A) = n$)。
> 10. $r(A)$ 等于非零特征值的个数 (仅限可对角化矩阵)。

## 三、 矩阵的高次幂计算

1. **秩一矩阵**：若 $A = \alpha \beta^T$，则 $A^n = [\text{tr}(A)]^{n-1} A$。
2. **三阶分解法**：若 $A = E + B$ 且 $B$ 是幂零矩阵 ($B^k = O$)，利用二项式展开。
3. **相似对角化**：若 $A = P \Lambda P^{-1}$，则 $A^n = P \Lambda^n P^{-1}$。

## 四、 矩阵方程 $AB = BA$ 的判定

> [!TIP] 什么时候可以交换？
> 1. $B$ 是 $A$ 的多项式：$B = f(A)$ (如 $A^{-1}, A^*, A^2+E$)。
> 2. $A, B$ 均可相似对角化，且拥有**完全相同**的特征向量组。
> 3. $A, B$ 均为实对称矩阵，且 $AB$ 也是实对称矩阵。
