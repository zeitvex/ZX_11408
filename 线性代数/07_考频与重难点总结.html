07 考频与重难点总结 ​

线性代数全科核心公式速查、计算题套路及易错辨析。

章节选择题大题总占比

二、核心公式速查 ​

行列式 ​

  • |kA|=kn|A|
  • |AB|=|A|⋅|B|
  • |A−1|=|A|−1
  • |A∗|=|A|n−1
  • |AT|=|A|

矩阵 ​

  • AA∗=|A|E
  • (AB)−1=B−1A−1
  • (AB)T=BTAT
  • r(AB)≤min(r(A),r(B))
  • AB=O⇒r(A)+r(B)≤n

特征值 ​

  • ∑λi=tr(A)
  • ∏λi=|A|
  • An 的特征值为 λn
  • A−1 的特征值为 1/λ
  • A∗ 的特征值为 |A|/λ

三、大题常见题型 ​

题型方法
求逆矩阵(A|E)→(E|A−1) 或 A−1=A∗/|A|
求基础解系化行最简形 → 自由变量赋值
特征值与对角化解特征方程 → 求特征向量 → 构造 P
正交对角化特征向量正交化 → 单位化 → 构造 Q
正定性判定特征值全正 / 顺序主子式全正
用相似求矩阵A=PΛP−1

四、易错辨析 ​

易错点正确理解
"AB=0⇒A=0 或 B=0"❌ 矩阵乘积为零不能推出因子为零
"A2=A⇒A=E 或 A=O"❌ 幂等矩阵有很多种
"r(A)+r(B)=r(A+B)"❌ 只有 r(A+B)≤r(A)+r(B)
"特征值相同则相似"❌ 还需要有足够的线性无关特征向量
"可逆矩阵一定正定"❌ 可逆只要 |A|≠0，正定要求特征值全正
"正交矩阵行列式=1"❌ 正交矩阵行列式为 ±1
"实对称矩阵特征值可能为复数"❌ 实对称矩阵特征值全为实数

冲刺建议

  1. 特征值与对角化计算必须又快又准
  2. Schmidt 正交化流程反复练习
  3. 方程组解的结构定理理解本质（非齐次通解 = 特解 + 齐次通解）
