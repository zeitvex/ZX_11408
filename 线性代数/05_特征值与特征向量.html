05 特征值与特征向量 ​

本章是线性代数最重要的考试章节，特征值求解、相似对角化和正交对角化几乎每年必考大题。

一、特征值与特征向量的概念 ​

Aξ=λξ（ξ≠0），则 λ 是 A 的特征值，ξ 是对应的特征向量。

1.1 求特征值 ​

解特征方程：|λE−A|=0

1.2 求特征向量 ​

对每个特征值 λi，解 (λiE−A)x=0，非零解即为特征向量。

二、特征值的性质 ​

  • λ1+λ2+⋯+λn=tr(A)=a11+a22+⋯+ann（迹）
  • λ1⋅λ2⋯λn=|A|
  • A 可逆 ⇔ 所有特征值不为 0

不同特征值对应的特征向量**线性无关**。

三、相似矩阵 ​

P−1AP=B，则 A 与 B 相似，记为 A∼B。

相似的必要条件 ​

  • 相同的特征值
  • 相同的秩
  • 相同的行列式
  • 相同的迹
  • 相同的特征多项式

相似对角化 ​

A 可对角化 ⇔ A 有 n 个线性无关的特征向量

⇔ 每个 k 重特征值 λi 有 k 个线性无关的特征向量，即 n−r(λiE−A)=k

对角化步骤：

  1. 求特征值 λ1,λ2,⋯,λn
  2. 求每个特征值对应的特征向量 ξ1,ξ2,⋯,ξn
  3. 令 P=(ξ1,ξ2,⋯,ξn)，则 P−1AP=Λ=diag(λ1,⋯,λn)

四、实对称矩阵的正交对角化 ​

4.1 实对称矩阵的性质 ​

  1. 特征值全为实数
  2. 不同特征值对应的特征向量正交
  3. 实对称矩阵一定可以对角化
  4. 存在正交矩阵 Q 使得 QTAQ=Λ

4.2 正交对角化步骤 ​

  1. 求特征值
  2. 求特征向量
  3. 同一特征值对应的特征向量若不正交，用 Schmidt 正交化
  4. 所有特征向量单位化
  5. 构造正交矩阵 Q=(η1,η2,⋯,ηn)

正交对角化是大题核心

务必熟练掌握：求特征值 → 求特征向量 → 正交化 → 单位化 → 构造 Q 矩阵。
