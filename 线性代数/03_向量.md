# 03 向量

> 向量组的线性相关性是理解线性方程组解的结构的理论基础。

## 一、向量组的线性组合

向量 $\beta$ 能被向量组 $\alpha_1, \alpha_2, \cdots, \alpha_s$ 线性表示 $\Leftrightarrow$ $x_1\alpha_1 + x_2\alpha_2 + \cdots + x_s\alpha_s = \beta$ 有解 $\Leftrightarrow$ $r(A) = r(\bar{A})$

## 二、线性相关与线性无关

- **线性相关**：存在**不全为零**的 $k_1, k_2, \cdots, k_s$ 使得 $k_1\alpha_1 + k_2\alpha_2 + \cdots + k_s\alpha_s = 0$
- **线性无关**：$k_1\alpha_1 + k_2\alpha_2 + \cdots + k_s\alpha_s = 0$ 只有**零解**

### 判定定理

| 条件 | 结论 |
|------|------|
| 向量个数 > 维数 | 必定**线性相关** |
| 含零向量 | 必定**线性相关** |
| 有一个向量能被其余线性表示 | **线性相关** |
| 部分相关 → 整体 | 整体**线性相关** |
| 整体无关 → 部分 | 部分**线性无关** |
| $r(\alpha_1, \cdots, \alpha_s) < s$ | **线性相关** |
| $r(\alpha_1, \cdots, \alpha_s) = s$ | **线性无关** |

> [!IMPORTANT] 线性相关的本质
> 线性相关 $\Leftrightarrow$ 齐次方程组 $Ax = 0$ 有非零解 $\Leftrightarrow$ $r(A) < n$（n 为向量个数）

## 三、极大线性无关组与秩

- **极大线性无关组**：向量组中一个**最大的线性无关子集**
- **向量组的秩**：极大线性无关组中向量的个数 = $r(A)$
- 等价向量组有**相同的秩**

## 四、向量空间（数一）

- **基**：向量空间的一个极大线性无关组
- **维数**：基中向量的个数
- **坐标**：向量在基下的线性组合系数
- **过渡矩阵**：$(\beta_1, \cdots, \beta_n) = (\alpha_1, \cdots, \alpha_n)P$

### Schmidt 正交化

将线性无关组 $\alpha_1, \alpha_2, \alpha_3$ 正交化：

$$\beta_1 = \alpha_1$$
$$\beta_2 = \alpha_2 - \frac{(\alpha_2, \beta_1)}{(\beta_1, \beta_1)}\beta_1$$
$$\beta_3 = \alpha_3 - \frac{(\alpha_3, \beta_1)}{(\beta_1, \beta_1)}\beta_1 - \frac{(\alpha_3, \beta_2)}{(\beta_2, \beta_2)}\beta_2$$

再单位化：$\eta_i = \frac{\beta_i}{|\beta_i|}$

> [!IMPORTANT] Schmidt 正交化必须熟练掌握，这是特征值章节正交对角化的基础。
