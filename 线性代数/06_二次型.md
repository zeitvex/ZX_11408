# 06 二次型

> 二次型是特征值理论的直接应用，核心在于正交变换化标准形和正定性判定。

## 一、二次型的定义

$$f(x_1, x_2, \cdots, x_n) = \sum_{i=1}^{n}\sum_{j=1}^{n} a_{ij}x_ix_j = x^TAx$$

其中 $A$ 是**对称矩阵**（$a_{ij} = a_{ji}$），称为二次型的矩阵。

## 二、标准形与规范形

- **标准形**：只含平方项 $f = d_1y_1^2 + d_2y_2^2 + \cdots + d_ny_n^2$
- **规范形**：标准形中系数仅为 $1, -1, 0$

## 三、化标准形的方法

### 3.1 正交变换法（实对称矩阵）

1. 写出二次型矩阵 $A$
2. 求 $A$ 的特征值和特征向量
3. 正交化、单位化 → 正交矩阵 $Q$
4. 令 $x = Qy$，则 $f = \lambda_1y_1^2 + \lambda_2y_2^2 + \cdots + \lambda_ny_n^2$

### 3.2 配方法

按某个变量逐一配方，将交叉项消去。适用于任意二次型。

## 四、惯性定理

- 不管用什么方法化标准形，标准形中**正项个数 p**（正惯性指数）和**负项个数 q**（负惯性指数）唯一确定
- $p + q \leq n$（$n - p - q$ 是系数为 0 的项数）

## 五、正定二次型

$f(x) > 0$ 对一切 $x \neq 0$ 成立，则 $f$ 是**正定**的，$A$ 是**正定矩阵**。

### 正定的充要条件

- 所有特征值 $> 0$
- 正惯性指数 $p = n$
- $A \cong E$（合同于单位矩阵）
- 所有**顺序主子式 > 0**

### 正定的必要条件

- $a_{ii} > 0$（主对角线元素全为正）
- $|A| > 0$

> [!IMPORTANT] 正定性判定
> 最快的方法：求特征值，判断是否全部大于 0。或者检验各阶顺序主子式是否全部大于 0。

## 六、合同矩阵

$C^TAC = B$（$C$ 可逆），则 $A$ 与 $B$ **合同**。

- 合同变换不改变**惯性指数**
- 实对称矩阵合同 $\Leftrightarrow$ 有相同的正、负惯性指数
