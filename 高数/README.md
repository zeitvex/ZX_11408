# 408 统考数学（一） 高等数学 —— 知识库总览

> 本资料库汇集了考研数学（一）中《高等数学》科目的全部核心知识点、重点难点梳理、错题复盘以及核心记忆公式，旨在为强化冲刺阶段提供全面、系统、无错漏的背诵与查阅资料。

---

## 📂 目录结构与内容说明

本模块根据数学一官方最新大纲设计，划分为核心的 9 个章节，并附加了强化冲刺所需的高频考点总结与复习大纲。

### 核心知识模块
- **[01_预备知识与基础公式](01_预备知识与基础公式.md)**: 三角函数公式、乘法公式、等价无穷小大全、基本不等式及导数与积分的前置基础。
- **[02_函数_极限_连续](02_函数_极限_连续.md)**: 极限定义与三大性质，七种未定式计算、泰勒展开核心运用、间断点类型。
- **[03_一元函数微分学](03_一元函数微分学.md)**: 导数计算、中值定理（罗尔、拉格朗日、柯西、泰勒）、导数的几何与物理应用。
- **[04_一元函数积分学](04_一元函数积分学.md)**: 积分基本表、分部与换元法大集结、广义积分的敛散性判定及各类几何物理应用。
- **[05_向量代数与空间解析几何](05_向量代数与空间解析几何.md)**: 空间直角坐标系、向量的点积和叉积、平面与直线方程及各种空间曲面模型。
- **[06_多元函数微分学](06_多元函数微分学.md)**: 偏导数全微分计算、梯度与方向导数、无条件与条件极值判断。
- **[07_多元函数积分学_重积分与曲线曲面积分](07_多元函数积分学_重积分与曲线曲面积分.md)**: 重积分不同坐标系计算、格林公式、高斯公式、斯托克斯公式及曲线曲面积分类比记忆。
- **[08_无穷级数](08_无穷级数.md)**: 正项/交错级数敛散性五大判别法、幂级数操作收敛域求法及函数麦克劳林/傅里叶展开。
- **[09_常微分方程](09_常微分方程.md)**: 一阶全微分/分离变量，二阶常系数齐次及非齐次特征方程法大全。

### 冲刺提分与框架
- **[00_考研高数一科目大纲与总览](00_考研高数一科目大纲与总览.md)**: 各章节考试要求，明确宏观结构和必考方向（基于历年最新大纲）。
- **[10_考频与重难点总结](10_考频与重难点总结.md)**: 包含核心计算陷阱（如级数边界条件、不同积分域判断）、历年易错点的整理与避坑指南。

## 💡 备考建议

1. **宏观把控**: 高等数学体系庞大。在阅读各章前，建议先通过大纲（`00` 号文件）看清所学内容处于考研数学框架的具体位置。
2. **重视计算**: 微积分和重积分的题目极其考验基本功，在看笔记时务必自己落笔推导！
3. **重视公式**: 笔记中的公式一定要背过、背熟。不要有看到形似的题目却写不出变形公式的遗憾。
