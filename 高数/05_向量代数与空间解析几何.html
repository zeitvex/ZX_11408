已是高中熟悉的知识，此处不再赘述

2. 向量积 ​

设 a=(ax,ay,az),b=(bx,by,bz)，则：

a×b=|ijkaxayazbxbybz|

被就是向量积。设 a,b 的夹角为 θ，则 |a×b|=|a||b|sin⁡θ，向量积的方向可由右手规则确定：

向量积的性质：

  • a×b=−b×a
  • 分配律：(a+b)×c=a×c+b×c
  • 与数乘的结合律：(λa)×b=a×(λb)=λ(a×b)

3. 混合积 ​

先将两向量 a,b 的向量积 a×b，所得到的向量再与一个向量做数量积 (a×b)⋅c 这样得到的一个数量叫做 a,b,c 的混合积，记作 [abc]

假设 a=(ax,ay,az),b=(bx,by,bz),c=(cx,cy,cz)，则：

[abc]=|axayazbxbybzcxcycz|

混合积的绝对值表示以这三个向量为棱的平行六面体的体积，三个向量共面的充要条件是混合积为 0

三、平面及其方程 ​

考纲摘要：

  1. 掌握平面方程和直线方程及其求法
  2. 会求平面与平面、平面与直线、直线与直线之间的夹角，并会利用平面、直线的相互关系（平行、垂直、相交等））解决有关问题
  3. 会求点到直线以及点到平面的距离

1. 曲面方程与空间曲线方程的概念 ​

如果曲面 $S $ 与三元方程 $ F(x, y, z) = 0$ 有以下关系：

  • 曲面 $S $ 上任意一点的坐标都满足方程 $ F(x, y, z) = 0$
  • 不在曲面 $S $ 上的点的坐标都不满足 $ F(x, y, z) = 0$

那么方程 $F(x, y, z) = 0 $ 就叫做曲面 $ S$ 的方程，曲面 $S $ 就叫做方程 $ F(x, y, z) = 0$ 的图形

而空间曲线可以看作是两个曲面的交线，曲线的方程可以写为：

{F(x,y,z)=0G(x,y,z)=0

曲线 $C $ 就可以用这样的方程组来表示，这个方程组就叫做空间曲线 $ C$ 的方程，曲线 C 就叫做这个方程组的图形

2. 平面的点法式方程 ​

如果一个非零向量与一个平面垂直，那么这个向量就叫做这个平面的法线向量，易知，平面上任意一点都和法线向量垂直。这样一来，知道平面上的一个点与这个平面的其中一个法线向量，就可以完全确定这个平面了。

设 M(x, y, z) 是平面 Π 上的任一点，向量 M0M→，必定与法线向量 n 垂直，也就是：n⋅M0M→=0

因为

n=(A,B,C),M0M→=(x−x0,y−y0,z−z0)

也就有：

A(x−x0)+B(y−y0)+C(z−z0)=0

这就是一个平面上的任意一点 M(x,y,z) 的坐标所满足的方程。这种形式的空间平面方程就是点法式方程

3. 平面的一般方程 ​

任何平面都可以用三元一次方程 Ax+By+Cz+D=0 来表示向量 (A,B,C) 就是这个平面的一个法线向量

一些特殊的三元一次方程的图形特点：

  • $D=0 $ 时，也就是 $ Ax + By + Cz = 0$ ，表示一个通过原点的平面

  • $A=0 $ 时， $ By + Cz + D = 0$ 的法线向量 b=(0,B,C) 垂直于 $x $ 轴，方程表示一个平行于 $ x$ 轴的平面

    同理， $Ax + Cz + D = 0 $ 和 $ Ax + By + D = 0 $ 也分别于 $ y$ 轴、z 轴平行。

截距式方程：

xa+yb+zc=1

a,b,c 是平面在 x,y,z 轴上的截距

4. 两平面的夹角 ​

两个平面的法线向量的夹角（通常指锐角或直角），称为两平面的夹角

设两个平面的方程为：A1x+B1y+C1z+D=0,A2x+B2y+C2z+D=0，则显然它们的法向量分别为：n1=(A1,B1,C1),n2=(A2,B2,C2)

cosθn1⋅n2|n1||n2|=|A1A2+B1B2+C1C2|A12+B12+C12A22+B22+C22

5. 点到平面的距离公式 ​

点 (x0,y0,z0) 到平面 Ax+By+Cz+D=0 的距离公式：

d=|Ax0+By0+Cz0+D|A2+B2+C2

四、空间直线及其方程 ​

考纲摘要：

  1. 掌握平面方程和直线方程及其求法
  2. 会求平面与平面、平面与直线、直线与直线之间的夹角，并会利用平面、直线的相互关系（平行、垂直、相交等））解决有关问题
  3. 会求点到直线以及点到平面的距离

1. 空间直线的方程 ​

1. 空间直线的一般方程 ​

[A1B1C1A2B2C2][xy]=[−D1−D2](或者{A1x+B1y+C1z+D1=0A2x+B2y+C2z+D2=0)

系数矩阵的秩必须为 2，否则就意味着两个平面是平行的，无法确定一条唯一的直线。

2. 空间直线的对称式方程 ​

平行于直线 $L $ 的向量叫做它的方向向量 可以通过空间中的已知点 $ M_0(x_0,y_0,z_0)$ 和它的一个方向向量 s=(m,n,p) 来唯一确定一个 L 的方程

这样确定出的 L 的方程为：

x−x0m=y−y0n=z−z0p

这样的方程称作直线的对称式方程或点向式方程

考虑 m,n,p 中含有 0 的情形：

  • 当 m=0 时，方程组实际上是 {x−x0=0y−y0n=z−z0p
  • 当 $m=0,n=0 $ 时，实际上这就是一个和 $ z$ 轴平行的直线，方程组为 {x−x0=0y−y0=0

3. 空间直线的参数方程 ​

对称式方程可以直接导出直线的参数方程：

{x=x0+mty=y0+ntz=z0+pt

2. 两直线的夹角 ​

直接根据数量积的定义求两直线的方向向量的夹角即可，注意方向向量的方向，两直线的夹角要取锐角或者钝角

3. 直线与平面的夹角 ​

设直线与平面的夹角为 θ，则直线与平面的法向量的夹角为 π/2−θ，然后直接根据数量积的定义求夹角即可

五、曲面及其方程 ​

考纲摘要：

  1. 了解曲面方程和空间曲线方程的概念
  2. 了解常用二次曲面的方程及其图形，会求简单的柱面和旋转曲面的方程

1. 曲面方程的概念 ​

定义：如果曲面 $S $ 与方程 $ F(x,y,z)=0$ 有以下关系：

  • 曲面 S 上任意点的坐标满足这个方程
  • 不在曲面 S 上的点的坐标不满足这个方程

那么这个方程 $F(x,y,z)=0 $ 就叫做曲面 $ S$ 的方程，曲面 $S $ 的叫做方程 $ F(x,y,z)=0$ 的图形

在空间解析几何中，关于曲面的研究有以下两个基本问题：

  1. 已知一曲面作为点的几何轨迹时，建立这个曲面的方程
  2. 已知坐标 x,y,z 间的一个方程时，研究这个方程所表示的曲面的形状

2. 旋转曲面 ​

定义：一条平面曲线绕其平面上一条定直线旋转一周形成的曲面叫做旋转曲面，该定直线称为轴，这条曲线称为母线

给定 yOz 面上的一条曲线 C:f(y,z)=0，那么这个曲线环绕Z轴形成的旋转曲面的方程为：

f(±x2+y2,z)=0

3. 柱面 ​

定义：平行定直线并沿着定曲线 $C $ 移动的直线 $ l$ 形成的轨迹叫做柱面，$C $ 叫做准线，l 叫做母线

4. 二次曲面 ​

把三元二次方程 F(x,y,z)=0 表示的曲面称作二次曲面

F(x,y,z)=Ax2+By2+Cz2+Dxy+Eyz+Fzx+Gx+Hy+Iz+J=0

其基本类型有：椭球面、抛物面、双曲面、锥面研究二次曲面特性的基本方法：截痕法

1. 椭球面 ​

x2a2+y2b2+z2c2=1

与坐标面的交线是椭圆

{x2a2+y2b2=0z=0{z2c2+y2b2=0x=0{x2a2+z2c2=0y=0

截痕：与 z=z1 的交线是椭圆

{x2a2c2(c2−z12)+x2b2c2(c2−z12)=1z=z1

当 $a = b $ 时是旋转椭球面。当 $ a = b = c$ 时是球面。

2. 抛物面 ​

椭圆抛物面

x22p+y22q=z

特别的，当 p=q 的时候就是绕z轴的旋转抛物面

双曲抛物面（鞍型曲面）

−x22p+y22q=z

注意，以上 $p $ 和 $ q$ 均同号。

3. 双曲面 ​

单叶双曲面

x2a2+y2b2−z2c2=1

平面 z=z1上的截痕是椭圆

平面 y=y1 上的截痕情况：

  • |y1|<b 时，截痕为双曲线

  • {x2a2−z2c2=1−y12b2y=y1

    双叶双曲面

    x2a2+y2b2−z2c2=−1

4. 椭圆锥面 ​
