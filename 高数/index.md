## 🎯 提分与回顾

- **[00 考研高数一科目大纲与总览](00_考研高数一科目大纲与总览.md)**：各章节考试要求，明确宏观结构和必考方向（基于历年最新大纲）。

**分值分布**（高数约 82 分，占数一半壁江山）：极限、一元与多元积分学、级数、微分方程均为大题常客；多元积分学（三大公式）是难点集中区。

**必背速查**

| 主题 | 一句话结论 |
| :--- | :--- |
| 等价无穷小（$x\to 0$） | $\sin x\sim\tan x\sim\arcsin x\sim\arctan x\sim\ln(1+x)\sim e^x-1\sim x$ |
| 高阶等价 | $x-\sin x\sim\dfrac{x^3}{6}$，$1-\cos x\sim\dfrac{x^2}{2}$，$\tan x-x\sim\dfrac{x^3}{3}$ |
| 洛必达前提 | 必须是 $\frac00$ 或 $\frac\infty\infty$，且求导后极限存在或为 $\infty$ |
| 可导与连续 | 可导 $\Rightarrow$ 连续；连续 $\not\Rightarrow$ 可导 |
| 中值定理选择 | 一个中值点用拉格朗日；两个用柯西或两次拉格朗日；带高阶导用泰勒 |
| $p$ 级数 | $\sum 1/n^p$：$p>1$ 收敛，$p\le 1$ 发散 |
| 反常积分 | $\int_1^{+\infty}\frac{dx}{x^p}$：$p>1$ 收敛；$\int_0^1\frac{dx}{x^p}$：$p<1$ 收敛 |
| 三大公式 | 格林（平面闭曲线）、高斯（闭曲面）、斯托克斯（空间闭曲线） |
| 二阶常系数非齐次 | 特解形式看 $\lambda$ 是否为特征根，是则乘 $x^k$ |

**高频易错**

1. 用等价无穷小替换只能用于**乘除**，加减中替换会出错（需用泰勒）。
2. $\sqrt{u^2}=\lvert u\rvert$，换元去根号时漏绝对值是经典失分点。
3. 分段函数在分界点求导必须用**定义**，不能分别求导后代入。
4. 反常积分与定积分的换元，注意上下限是否同时变号。
5. 用格林 / 高斯公式前必须检查**是否封闭、是否有奇点**，不闭要补线补面。
6. 幂级数收敛域别忘了**单独讨论端点**。
7. 条件极值用拉格朗日乘数法后，还需比较边界值才能定最值。
