# 伪代码版本 / C++ 版本

> **用途**: 考卷手写（推荐）。不含 `main()`，不可单独编译运行。

## 语法风格
- C++ 引用 `&` 风格: 参数传递用引用，避免繁琐的二级指针
- 408 阅卷标准中明确允许使用 `&` 引用及简单 STL (`<stack>`, `<queue>`)
- 不使用 C++11/14/17 等新特性

## 文件清单

| 文件 | 内容 |
|:---|:---|
| `01_线性表.cpp` | 顺序表增删 / 单链表头插尾插 (引用风格) |
| `02_栈和队列.cpp` | 顺序栈 / 循环队列(引用风格) |
| `03_树与层序遍历.cpp` | 三序递归+非递归 / 层序(STL queue) / AVL判别 / 并查集 |
| `04_排序算法.cpp` | 八大排序伪代码 + 归并 + Partition变式 |
| `05_串与查找.cpp` | KMP(next+nextval) / 折半查找 |
| `06_图的核心算法.cpp` | DFS/BFS(STL queue) / Dijkstra |

## 为什么推荐 C++ 版本?
考场上 C++ 的引用 `&` 让参数传递清晰一目了然，免去 C 中大量的 `*L`、`(*L)->next` 等解引用操作，**降低手写出错概率，节省宝贵时间**。
