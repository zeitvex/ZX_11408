# 伪代码版本 / C 版本

> **用途**: 考卷默写、考前速背。不含 `main()`，不可单独编译运行。

## 语法风格
- 纯 C 指针风格: 参数传递用 `*` 指针
- 与严蔚敏教材一致
- 不使用 C99+ 新特性

## 文件清单

| 文件 | 内容 |
|:---|:---|
| `01_线性表.c` | 顺序表增删 / 单链表头插尾插 / 快慢指针 |
| `02_栈和队列.c` | 顺序栈 / 循环队列(牺牲单元法) |
| `03_树与层序遍历.c` | 三序递归+非递归 / 层序 / 求深度 / AVL判别 / 并查集 |
| `04_排序算法.c` | 快排+Partition / 堆排+AdjustDown / 折半插入 / 归并 / 奇偶划分 |
| `05_串与查找.c` | KMP(next+nextval) / 折半查找(递归+非递归) |
| `06_图的核心算法.c` | DFS/BFS(邻接表) / Dijkstra / 拓扑排序 |
