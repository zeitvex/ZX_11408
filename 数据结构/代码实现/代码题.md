## 一、历年真题算法大题

### 2009 年：单链表中查找倒数第 k 个结点

**题目**：在带头结点的单链表中，查找倒数第 k 个结点的值。

**思路**：双指针法
- p、q 都从头结点出发，p 先走 k 步
- 然后 p、q 同时走，p 到末尾时 q 正好在倒数第 k 个

**时间 O(n)，空间 O(1)，一趟扫描**

---

### 2010 年：数组循环左移 p 位

**题目**：将数组 `a[0..n-1]` 中的元素循环左移 `p` 个位置。要求时间 O(n)、空间 O(1)。

**思路**：三次逆置法
1. 逆置 `a[0..p-1]`
2. 逆置 `a[p..n-1]`
3. 整体逆置 `a[0..n-1]`

**对应代码**：`可运行版本/c版本/01_线性表_顺序表.c` → `LeftShift()`

---

### 2011 年：两个等长有序序列求中位数

**题目**：两个等长升序序列 A、B 各含 n 个元素，找出两者合并后的中位数。

**思路**：双指针归并计数 O(n)
- 两指针分别从 A、B 头出发
- 每次移动较小者的指针，计数至第 n 个即为中位数

**对应代码**：`可运行版本/c版本/01_线性表_顺序表.c` → `FindMedian()`

---

### 2012 年：单链表中删除最小值结点

**题目**：给定带头结点的单链表 L，删除其中值最小的结点（假设唯一最小）。

**思路**：遍历找最小值的前驱
- 设 minpre 记录最小值结点的前驱
- 遍历一遍找到后，执行 `minpre->next = minpre->next->next` 删除

---

### 2013 年：寻找主元素

**题目**：若数组中某元素出现次数 > n/2，称为主元素。找出并返回它，不存在返回 -1。

**思路**：摩尔投票法 O(n)、O(1)
- 第一遍：候选者计数，相同+1 不同-1，归零换人
- 第二遍：验证候选者出现次数是否真的 > n/2

**对应代码**：`可运行版本/c版本/01_线性表_顺序表.c` → `FindMainElement()`

---

### 2014 年：求二叉树的 WPL（带权路径长度）

**题目**：给定一棵二叉树，每个结点有权值，求所有**叶子**结点的带权路径长度之和。

**思路**：递归
- 叶子结点：返回 `权值 × 深度`
- 非叶子：递归左右子树求和

**对应代码**：`可运行版本/c版本/04_二叉树.c` → `CalcWPL()`

---

### 2015 年：删除有序链表中的重复结点

**题目**：删除递增有序链表中所有**值重复**的结点（保留一个或全删，视题意）。

**思路**：
- 扫描链表，比较相邻结点
- 值相同则删后继，不同则前移指针

---

### 2016 年：两棵二叉排序树合并

**题目**：将两棵二叉排序树合并为一棵。

**思路**：
- 分别中序遍历得到两个有序序列
- 归并两个有序序列
- 用归并后的有序序列构建平衡 BST

---

### 2017 年：用后序遍历求表达式树的值

**题目**：给定一棵表达式二叉树（叶子为操作数，内部结点为运算符），求表达式的值。

**思路**：后序递归
- 叶子结点返回其操作数值
- 非叶子：先递归得左右值，再根据运算符计算

---

### 2018 年：未出现的最小正整数

**题目**：给定含 n 个整数的数组，找出其中未出现的最小正整数。要求 O(n)。

**思路**：种树法/哈希标记
- 建立辅助数组，将出现的正整数标记对应位置
- 遍历辅助数组，第一个未标记的下标即答案

---

### 2019 年：用 BST 判断两序列是否构建同一棵树

**思路**：分别建树后比较，或直接比较插入序列的等价性。

## 二、高频必考代码考点总结

以下算法几乎**年年涉及**（选择题需要理解执行过程，大题可能要求手写）：

### 线性表

| 考点 | 说明 | 难度 |
|:---|:---|:---:|
| 顺序表插入删除 | 元素后移/前移，注意下标换算 | ★ |
| 头插法建链表 | 结果与输入顺序相反，常用于逆置 | ★★ |
| 尾插法建链表 | 需要尾指针 r，最后 `r->next=NULL` | ★★ |
| 链表原地逆置 | 头插法逆置，O(n)/O(1) | ★★★ |
| 快慢指针找中间 | 快走2慢走1 | ★★ |
| 双指针找倒数第k个 | 一个先走k步 | ★★ |
| 链表排序 | 直接插入排序思路 | ★★ |

### 栈与队列

| 考点 | 说明 | 难度 |
|:---|:---|:---:|
| 顺序栈操作 | `top=-1`，先加后存 | ★ |
| 循环队列 | 牺牲单元法判空满 | ★★ |
| 括号匹配 | 左括号入栈，右括号配对 | ★★ |
| 后缀表达式求值 | 数入栈，遇运算符弹两个 | ★★★ |
| 非递归遍历(栈) | 中序/后序的栈模拟 | ★★★ |

### 串

| 考点 | 说明 | 难度 |
|:---|:---|:---:|
| KMP next数组 | 选择题必考手算，大题可能要写代码 | ★★★ |
| KMP nextval | next 的优化，防止相同字符重复比较 | ★★★ |
| KMP 匹配过程 | 主串不回溯，模式串利用 next 跳转 | ★★★ |

### 树与二叉树

| 考点 | 说明 | 难度 |
|:---|:---|:---:|
| 先/中/后序递归 | 三行代码，必须秒写 | ★ |
| 中序非递归 | 一路向左入栈，弹栈访问，转右 | ★★★ |
| 层序遍历 | 队列实现 BFS | ★★ |
| 求树深度 | max(左深,右深)+1 | ★★ |
| 求叶子数 | 左右孩子都空为叶子 | ★ |
| WPL | 叶子的权×深度之和 | ★★ |
| AVL 判别 | 后序遍历一边求高一边判差 | ★★★ |
| 并查集 | Find(路径压缩) + Union(按秩合并) | ★★★ |

### 图

| 考点 | 说明 | 难度 |
|:---|:---|:---:|
| DFS | 递归，visited 标记 | ★★ |
| BFS | 队列，visited 标记 | ★★ |
| Dijkstra | 贪心，dist 数组 + 松弛 | ★★★ |
| 拓扑排序 | 入度为0入栈，出栈削边 | ★★★ |

### 排序

| 考点 | 说明 | 稳定? | 时间 |
|:---|:---|:---:|:---|
| 直接插入 | 有序区逐个插入 | ✓ | O(n²) |
| 折半插入 | 查找用二分，移动不变 | ✓ | O(n²) |
| 希尔排序 | 分组插入排序 | ✗ | ≈O(n^1.3) |
| 冒泡排序 | 相邻交换，设 flag | ✓ | O(n²) |
| 快速排序 | Partition 划分，递归 | ✗ | O(nlogn) |
| 选择排序 | 每趟选最小 | ✗ | O(n²) |
| 堆排序 | 大顶堆，A[0]暂存 | ✗ | O(nlogn) |
| 归并排序 | 二路归并，辅助数组 | ✓ | O(nlogn) |

### 查找

| 考点 | 说明 | 难度 |
|:---|:---|:---:|
| 折半查找 | 有序数组，O(logn) | ★★ |
| BST查找/插入 | 二叉排序树的递归 | ★★ |
