# 数据结构·代码实现

408 数据结构的算法代码分为两套，分别服务于**考场手写**与**上机验证**两种场景。

## 两个版本的区别

| 版本 | 用途 | 特点 |
| :--- | :--- | :--- |
| 伪代码版本 | **考场默写** | 贴近王道 / 教材的书写习惯，省略 I/O 与内存细节，聚焦算法主干 |
| 可运行版本 | **上机验证** | 可直接 `gcc` / `g++` 编译执行，含 `main` 测试用例与真题实现 |

> 统考代码题按**伪代码**评分，不要求可编译；但亲手跑通一遍可运行版本，对理解指针操作与边界条件帮助极大。
