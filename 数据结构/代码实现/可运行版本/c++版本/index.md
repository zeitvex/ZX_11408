# 可运行版本 / C++ 版本

> **用途**: 编译运行、调试理解。每个文件含 `main()` 和测试数据。

## 编译方法
```bash
g++ "01_线性表.cpp" -o test.exe
./test.exe
```

## 语法风格
- C++ 引用 `&` 风格参数传递
- 使用 `bool` / `true` / `false`
- 不使用 C++11/14/17 新特性（如 auto、范围for、lambda 等均不用）
