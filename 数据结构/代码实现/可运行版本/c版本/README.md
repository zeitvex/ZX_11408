# 可运行版本 / C 版本

> **用途**: 真正编译运行、调试理解。每个文件含 `main()` 和测试数据。

## 编译方法
```bash
gcc "01_线性表_顺序表.c" -o test.exe
./test.exe
```

## 语法风格
- 纯 C 语言，兼容 C89/C99
- 不依赖任何 C++ 特性
- 变量在代码块头部声明

| 文件 | 覆盖内容 | 特色 |

## 使用建议
1. 先运行看输出 → 建立直觉
2. 修改测试数据 → 观察变化
3. 加 `printf` 追踪变量 → 理解过程
4. 对照笔记 → 搭配 `数据结构/01~08_xxx.md`
5. 关掉文件默写 → 考前训练
